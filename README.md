# ALPHA Ver 0.1

## Etherial RP

Fantasy RPG Discord bot dengan fokus pada sistem karakter, battle, eksplorasi, inventory, dan skill.

## Features

### Character System
- 15 race dengan base stats unik
- 10 job/class dengan identitas masing-masing
- Level system dengan experience
- Main stats: STR, AGI, VIT, INT, DEX, LUK
- Sub stats otomatis: ATK, MATK, DEF, MDEF, HIT, CRITICAL, FLEE, ASPD

### Battle System
- PvP turn-based battle
- Hit/miss calculation berdasarkan HIT vs FLEE
- Critical hit multiplier 1.5x
- Skill-based attack dan auto-attack
- Defense reduction dengan batas maksimum

### Exploration System
- 6 region dengan 45+ location
- Random enemy encounter
- Reward experience dan loot

### Inventory System
- Item rarity: common, uncommon, rare, epic, legendary
- Equipment slot untuk weapon, armor, dan accessory
- Weight limit
- Item stacking

### Skill System
- 20+ skill unik
- Skill cooldown
- AOE dan single-target skill
- Elemental damage type
- Skill progression berdasarkan level

### Commands
- `/register`
- `/profile`
- `/stats`
- `/skills`
- `/inventory`
- `/battle`
- `/explore`

### Data System
- Character data tersimpan di Firebase
- Race, job, skill, item, dan map terpisah di database
- Starter kit untuk karakter baru
